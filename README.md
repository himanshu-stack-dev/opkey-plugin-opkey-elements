# Opkey Custom Elements for Breakdance

This plugin contains custom elements and reusable components built specifically for the Opkey site, using the Breakdance visual builder.

## What's Included

- Breakdance-compatible custom elements stored in the `/elements/` directory
- Shared components tailored for Opkey’s design system
- Utility functions or logic (if applicable)

## How to Use

1. Install this plugin in `/wp-content/plugins/opkey-custom-elements/`
2. Activate it through the WordPress admin
3. All registered elements will appear in the Breakdance builder automatically

## Development Notes

- Breakdance will auto-load elements from this plugin during page editing.
- You can extend or modify the `elements/` folder to include new components.
- To share or reuse across projects, export elements via Breakdance's export tool.
